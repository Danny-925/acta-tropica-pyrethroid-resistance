# Pyrethroid Resistance Analysis in *Anopheles gambiae* s.l.

This repository contains R scripts, cleaned datasets, and analysis workflows used in the study:

> Balogun D, et al. (2026).  
> *Urban adaptation and pyrethroid resistance driven by molecular resistance mechanisms in Anopheles coluzzii populations from a peri-urban setting in southwestern Nigeria*.  
> Acta Tropica.

---

## Published Article

DOI: https://doi.org/10.1016/j.actatropica.2026.108119

---

## Repository Structure

```text
data/      -> cleaned datasets
scripts/   -> R scripts used for statistical analysis
figures/   -> generated plots and figures
```

---

## Analyses Included

- Descriptive statistics
- Insecticide susceptibility analysis
- Confidence interval estimation
- Probit regression analysis
- Knockdown time estimation
- Data visualization using ggplot2

---

## Software Requirements

Analyses were conducted in R.

Main packages used include:

- ggplot2
- dplyr
- MASS
- readr

---

## Reproducibility

The scripts are organised sequentially to facilitate reproducibility of the analyses presented in the published study.
