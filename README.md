# Pyrethroid Resistance Analysis in Anopheles gambiae s.l.

This repository contains R scripts and supporting materials used for statistical analysis and visualisation in the study:

"Urban adaptation and pyrethroid resistance driven by molecular resistance mechanisms in Anopheles coluzzii populations from a peri-urban setting in southwestern Nigeria"

Published in Acta Tropica (2026).

## Repository Structure

- `data/`: cleaned datasets
- `scripts/`: R analysis scripts
- `figures/`: generated plots

## Analyses Included

- Descriptive statistics
- Confidence interval estimation
- Probit regression analysis
- Knockdown time estimation
- Figure generation
